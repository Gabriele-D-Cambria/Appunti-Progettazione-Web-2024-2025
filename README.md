## 📋 Modalità d'Esame

### Prova Pratica

Sviluppo di un'app lato client (HTML - CSS - JavaScript), utilizzando
VSCode. Si hanno 2 ore di tempo, e sono permesse le slide incluse nel pacchetto
software del corso.

I testi, con le relative soluzioni, delle prove pratiche passate sono disponibili
sul [GitHub del professore](https://github.com/alessiovecchio/PWEB).

### Prova Orale

Vi si accede solo se il voto alla prova pratica è >=15. Il voto della prova pratica
viene mantenuto per 3 appelli.

L'orale consiste in un progetto, da consegnare entro il terzo giorno solare che
precede la data dell'esame (scritto il 17 -> consegna entro 23:59:59 del 14),
da effettuare al link fornito dal prof.

È necessario illustrare come è stato sviluppato, motivando le scelte progettuali.
È valutata anche l'esposizione e la terminologia.

Se si è beccati ad aver copiato il progetto, all'orale il professore chiederà qualsiasi
cosa.

Il progetto deve seguire le seguenti specifiche:

- Funzionalità Coese, non ridondanti, modulari e leggibili
- HTML, CSS, JavaScript, DOM Level 3, PHP, MySQL.
- Deve funzionare sia con Chrome che con Firefox
- Componente lato client e lato server
- Validatori: (link sul PDF)
- Consegna tramite Google Form, zippare la cartella principale
- Database da esportare tramite script salvato come: `"cognome_numerodimatricola"`
